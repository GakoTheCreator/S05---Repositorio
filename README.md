# Inatel Conecta - Assistência

Protótipo front-end responsivo para a disciplina Homem-Máquina, focado em assistência no app/site do Inatel.

## Visualização

GitHub Pages: https://gakothecreator.github.io/S05---Repositorio/

## Entrega

O PDF final está em `entrega/Entrega_Final_Inatel_Conecta_Gabriel_Ribeiro.pdf`.

## Scripts

- `npm run dev`: executa o projeto localmente.
- `npm run build`: gera exportação estática em `out/`.
- `npm run lint`: valida o código com ESLint.
